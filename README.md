ap-logkeeper
============

A minimal tool for tracking specific logs from an [Archipelago](https://github.com/ArchipelagoMW/Archipelago) multiworld.
Useful for sharing progression items in asyncs.

`./gradlew installDist`, then `./build/install/ap-logkeeper/bin/ap-logkeeper` to run.
Requires Java 25.
